## 第17回　提取类、移动方法、参数对象／值对象

### 第17回　クラス抽出・メソッド移動・パラメータオブジェクト／値オブジェクト

------

## 中文版

### 引言

在类级别的重构中，常见的目标是解决：

- **巨型类（Large Class）**
- **Feature Envy（方法归属错误）**
- **过长参数列表**
- **基本类型偏执** 与 **数据泥团**

对应的典型手法就是：

- **提取类（Extract Class）**
- **移动方法（Move Method）**
- **引入参数对象（Introduce Parameter Object）**
- **引入值对象（Introduce Value Object）**

------

### 17.1 提取类（Extract Class）

**适用场景**：类承担了多个不相关的职责。

```
// Before：User 类过于臃肿
class User {
  String name;
  String email;
  String address;
  String creditCard;
  String expiry;

  void updateProfile(String newName, String newEmail) { ... }
  void charge(double amount) { ... }
}
// After：提取 BillingInfo 类
class User {
  String name;
  String email;
  String address;
  BillingInfo billing;
}

class BillingInfo {
  String creditCard;
  String expiry;
  void charge(double amount) { ... }
}
```

✅ 好处：职责分离，更易测试与扩展。

------

### 17.2 移动方法（Move Method）

**适用场景**：方法频繁访问其他类的数据。

```
// Before
class Customer(val level: Int)

class Order(val amount: Double, val customer: Customer) {
    fun discount(): Double {
        return if (customer.level > 3) amount * 0.9 else amount
    }
}
// After：移动 discount 方法
class Customer(val level: Int) {
    fun discount(amount: Double): Double {
        return if (level > 3) amount * 0.9 else amount
    }
}

class Order(val amount: Double, val customer: Customer) {
    fun finalPrice() = customer.discount(amount)
}
```

✅ 好处：逻辑归属自然，降低类间耦合。

------

### 17.3 参数对象（Parameter Object）

**适用场景**：方法参数过长，且参数常常成组出现。

```
// Before
fun createUser(name: String, email: String, age: Int, address: String, phone: String) { ... }
// After：引入参数对象
data class UserProfile(
    val name: String,
    val email: String,
    val age: Int,
    val address: String,
    val phone: String
)

fun createUser(profile: UserProfile) { ... }
```

✅ 好处：调用简洁，参数扩展更自然。

------

### 17.4 值对象（Value Object）

**适用场景**：基本类型偏执，用裸字符串/数字表示复杂概念。

```
// Before
class User(val name: String, val email: String, val phone: String)
// After：引入值对象
data class Email(val value: String) {
    init { require(value.contains("@")) { "Invalid email" } }
}
data class Phone(val value: String)

class User(val name: String, val email: Email, val phone: Phone)
```

✅ 好处：语义更明确，约束更内聚，避免错误输入。

------

### 小结

- **提取类**：拆分职责，解决巨型类。
- **移动方法**：逻辑归属正确，降低耦合。
- **参数对象**：简化调用，解决过长参数列表。
- **值对象**：增强语义，解决基本类型偏执。

> 类级别重构的核心思想：**让对象承担合适的职责，保持高内聚、低耦合。**

## 日本語版

### 序文

クラスレベルのリファクタリングは、次のような問題を解決することが目的です：

- **巨大クラス（Large Class）**
- **Feature Envy（メソッドの所在不適切）**
- **長すぎる引数リスト**
- **基本型執着／データの塊**

これに対応する代表的な手法は：

- **クラス抽出（Extract Class）**
- **メソッド移動（Move Method）**
- **パラメータオブジェクト導入（Introduce Parameter Object）**
- **値オブジェクト導入（Introduce Value Object）**

------

### 17.1 クラス抽出（Extract Class）

```
// Before：User クラスが肥大化

  void charge(double amount) { ... }
```

✅ メリット：責務分離、テスト・拡張容易。

### まとめ

- **クラス抽出**：責務分離で巨大クラスを解体。
- **メソッド移動**：ロジックを正しいクラスに配置。
- **パラメータオブジェクト**：引数リストを簡潔に。
- **値オブジェクト**：意味付けと制約を強化。

> クラスレベルのリファクタリングの基本思想：
