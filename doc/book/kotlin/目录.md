# 第一篇·语言基础（入门）

1. Kotlin 概览与环境搭建
   - Kotlin 与 Java 的关系、JVM/Native/JS 三平台
   - 安装与工具：IntelliJ IDEA/Gradle/Kotlin CLI
   - Hello Kotlin、REPL 与脚本 `.kts`
2. 基础语法
   - 变量与常量、类型推断、字符串模板
   - 表达式与语句、区间与条件表达式、`when`
3. 函数与作用域
   - 顶层函数、默认参数、命名参数、可变参数
   - 表达式函数体、内联函数基础、局部函数
4. 面向对象基础
   - 类与对象、构造器、属性与自定义访问器
   - 可见性修饰、`data`/`enum`/`object`/`companion`
5. Kotlin 类型系统（1）
   - 可空类型与空安全、`?`/`!!`/安全调用`?.`/Elvis`?:`
   - 智能类型推断、`is`/`as`、平台类型
6. 集合与常用标准库
   - `List/Set/Map`（可变/不可变）、解构声明
   - `let/run/also/apply/with` 五兄弟
7. 函数式编程入门
   - Lambda、闭包、函数类型、匿名函数
   - 高阶函数与常用集合操作（`map/filter/reduce`）

# 第二篇·进阶语法与范式（进阶）

1. 继承与多态、接口与抽象
   - `open`/`final`、接口默认实现、委托 by
2. 泛型与变型
   - 声明处/使用处变型（`out/in`）、星投影、型擦除
   - reified 泛型与内联函数
3. 密封类与 ADT（代数数据类型）
   - `sealed class/interface` 及穷尽性 `when`
4. 扩展与操作符重载
   - 扩展函数/属性、infix 中缀、解构与运算符重载
5. Kotlin 类型系统（2）
   - `Nothing`/`Unit`/`Any`/`Any?`、`lateinit`/`lazy`
   - 可空集合、协变/逆变实战
6. DSL 与注解处理
   - Kotlin DSL 设计原则、接收者为函数类型的 DSL
   - kapt 与 KSP 基础
7. 文件与序列化
   - I/O 基础、`kotlinx.serialization`、JSON/ProtoBuf
8. 并发入门：协程基础
   - `suspend`、`CoroutineScope`、`Job`、`Dispatcher`
   - 结构化并发、`withContext`、`async/await`

# 第三篇·并发与响应式（高级）
