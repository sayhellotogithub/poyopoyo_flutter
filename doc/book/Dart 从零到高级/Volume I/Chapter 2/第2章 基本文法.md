## **第2章 基本文法**

------

### **2.1 main() 関数とエントリーポイント**

Dart のすべてのプログラムは `main()` 関数から実行されます。

```
void main() {
  print('プログラムが開始しました');
}
```

- `main()` は必須のエントリーポイントです。
- `void` は戻り値がないことを意味します。
- `print()` は文字列をコンソールに出力します。

------

### **2.2 変数と定数**

Dart は強い型付けを持ちながら、型推論もサポートしています。

1. **var**：可変変数。型はコンパイル時に推論されます。

   ```
   var name = 'Dart';
   name = 'Flutter'; // 有効
   ```

2. **final**：実行時定数。一度だけ代入可能です。

   ```
   final today = DateTime.now();
   // today = DateTime(2020); // エラー
   ```

3. **const**：コンパイル時定数。コンパイル時に値が決まっていなければなりません。

   ```
   const pi = 3.14159;
   ```

------

### **2.3 データ型**

Dart の代表的な組み込み型：

- `int`：整数
- `double`：浮動小数点数
- `String`：文字列
- `bool`：真偽値（true / false）

例：

```
int age = 25;
double price = 19.9;
String message = 'こんにちは Dart';
bool isOpen = true;
```

------

### **2.4 コレクション型**

Dart は豊富なコレクションを提供しています。

1. **List（リスト、順序付きコレクション）**

   ```
   var numbers = [1, 2, 3];
   numbers.add(4);
   ```

2. **Set（集合、重複不可）**

   ```
   var fruits = {'apple', 'banana'};
   fruits.add('banana'); // 無視される、Set は重複を許さない
   ```

3. **Map（キーと値のペア）**

   ```
   var person = {
     'name': 'Anna',
     'age': 25,
   };
   print(person['name']);
   ```

------

### **2.5 演算子と式**

- **算術演算子**：`+ - * / %`

- **比較演算子**：`== != > < >= <=`

- **論理演算子**：`&& || !`

- **条件演算子（三項演算子）**：

  ```
  var result = age > 18 ? '大人' : '未成年';
  ```

- **ヌル安全演算子**：

  ```
  var name = null;
  print(name ?? 'デフォルト値'); // 出力: デフォルト値
  ```
