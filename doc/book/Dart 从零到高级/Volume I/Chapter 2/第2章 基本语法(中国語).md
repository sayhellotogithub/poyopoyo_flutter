## **第2章 基本语法**

------

### **2.1 main() 函数与入口**

在 Dart 中，所有程序都从 `main()` 函数开始执行：

```
void main() {
  print('程序开始运行');
}
```

- `main()` 是必需的入口点。
- `void` 表示函数不返回任何值。
- `print()` 会将内容输出到控制台。

------

### **2.2 变量与常量**

Dart 是强类型语言，但具备类型推断功能。

1. **var**：可变变量，类型由编译器推断

   ```
   var name = 'Dart';
   name = 'Flutter'; // 合法
   ```

2. **final**：运行时常量，只能赋值一次

   ```
   final today = DateTime.now();
   // today = DateTime(2020); // 错误
   ```

3. **const**：编译时常量，值必须在编译阶段确定

   ```
   const pi = 3.14159;
   ```

------

### **2.3 数据类型**

常见内置类型：

- `int`：整数
- `double`：浮点数
- `String`：字符串
- `bool`：布尔值（true/false）

示例：

```
int age = 25;
double price = 19.9;
String message = 'Hello Dart';
bool isOpen = true;
```

------

### **2.4 集合类型**

Dart 提供了丰富的集合类型：

1. **List（列表）**

   ```
   var numbers = [1, 2, 3];
   numbers.add(4);
   ```

2. **Set（集合，不重复）**

   ```
   var fruits = {'apple', 'banana'};
   fruits.add('banana'); // 无效，Set 不允许重复
   ```

3. **Map（键值对）**

   ```
   var person = {
     'name': 'Anna',
     'age': 25,
   };
   print(person['name']);
   ```

------

### **2.5 运算符与表达式**

- **算术运算**：`+ - * / %`

- **比较运算**：`== != > < >= <=`

- **逻辑运算**：`&& || !`

- **条件表达式**：

  ```
  var result = age > 18 ? '成人' : '未成年';
  ```

- **空安全运算符**：

  ```
  var name = null;
  print(name ?? '默认值'); // 输出 "默认值"
  ```
