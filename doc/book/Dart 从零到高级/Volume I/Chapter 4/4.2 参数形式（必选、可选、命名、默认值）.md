## **4.2 参数形式（必选、可选、命名、默认值）**

### 必选参数

这是最常见的参数形式，调用时必须传递。

```
void greet(String name) {
  print('你好, $name');
}

greet('Anna'); // ✅
```

------

### 可选位置参数

用 `[]` 包裹，表示参数可以省略。

```
void greet(String name, [int? age]) {
  print('Hello $name, age: $age');
}

greet('Anna');      // age=null
greet('Bob', 25);   // age=25
```

------

### 命名参数

用 `{}` 包裹，调用时需要写参数名。

```
void greet({String? name, int? age}) {
  print('Hello $name, age: $age');
}

greet(name: 'Anna', age: 20);
greet(age: 30); // 只传 age
```

#### required 修饰符

可以强制命名参数必须传入。

```
void greet({required String name, int age = 18}) {
  print('Hello $name, age $age');
}

greet(name: 'Anna'); // ✅
```

------

### 默认值

可以给参数指定默认值，省略时会自动使用。

```
void greet(String name, {int age = 18}) {
  print('Hello $name, age $age');
}

greet('Anna');        // age=18
greet('Bob', age: 25);
```

------

✅ **小结**

- Dart 的参数有三大类：**必选、可选位置、命名**。
- 命名参数可加 `required` 强制调用者必须传入。
- 默认值必须是编译时常量。
- 常见错误：
  - 忘记加 `required`，导致重要参数被遗漏。
  - 可选参数太多时不易维护，推荐改用命名参数。
