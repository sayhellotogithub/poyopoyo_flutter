## **4.2 パラメータの種類（必須・オプション・名前付き・デフォルト値）**

### 必須パラメータ

最も基本的な形式で、呼び出し時に必ず渡す必要があります。

```
void greet(String name) {
  print('こんにちは, $name');
}

greet('Anna'); // ✅
```

------

### 位置オプションパラメータ

`[]` で囲むと省略可能になります。

```
void greet(String name, [int? age]) {
  print('Hello $name, age: $age');
}

greet('Anna');    // age=null
greet('Bob', 25); // age=25
```

------

### 名前付きパラメータ

`{}` で囲み、呼び出し時に名前を指定します。

```
void greet({String? name, int? age}) {
  print('Hello $name, age: $age');
}

greet(name: 'Anna', age: 20);
```

------

#### equired 修飾子

名前付きパラメータに必須制約を付けることができます。

```
void greet({required String name, int age = 18}) {
  print('Hello $name, age $age');
}

greet(name: 'Anna'); // ✅
```

### デフォルト値

省略した場合に自動で使われる値を指定できます。

```
void greet(String name, {int age = 18}) {
  print('Hello $name, age $age');
}

greet('Anna');        // age=18
greet('Bob', age: 25);
```

------

✅ **まとめ**

- Dart のパラメータは **必須・位置オプション・名前付き** の3種類。
- 名前付きパラメータに `required` を付けると必須にできる。
- デフォルト値はコンパイル時定数でなければならない。
- よくある間違い：
  - `required` を忘れて重要な値を渡し忘れる。
  - オプションパラメータが増えすぎて可読性が下がる。
