## **4.3 無名関数とアロー関数**

### 無名関数

無名関数は名前を持たない関数で、コールバックや一時的な処理に使われます。

```
var list = [1, 2, 3];

list.forEach((int n) {
  print(n * n);
});
```

通常の関数と同じように引数や戻り値を持つことができ、外部変数をキャプチャすることも可能です。

------

### アロー関数

アロー関数は `=>` を使った簡潔な書き方で、1つの式を表すのに適しています。

```
var list = [1, 2, 3];

list.forEach((n) => print(n * 2));
```

これは次の関数と同じ意味になります：

```
(n) {
  return n * 2;
}
```

------

✅ **まとめ**

- 無名関数は柔軟で複数行の処理にも対応。
- アロー関数は一行の式に最適で、コレクション操作でよく使われる。
- よくある間違い：
  - アロー関数に複数行の文を書こうとする。
  - 複雑な処理を無名関数に詰め込みすぎて読みづらくする。
