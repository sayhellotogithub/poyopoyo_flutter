- ## **4.3 无名函数与箭头函数**

  ### 无名函数

  无名函数（匿名函数）就是没有名字的函数，常用于回调或一次性的逻辑处理。

  ```
  var list = [1, 2, 3];
  
  list.forEach((int n) {
    print(n * n);
  });
  ```

  它和普通函数一样，可以有参数、返回值，还能捕获外部变量形成闭包。在集合遍历、事件回调中非常常见。

  ------

  ### 箭头函数

  箭头函数是无名函数的简写，用 `=>` 来表达单个表达式。

  ```
  var list = [1, 2, 3];
  
  list.forEach((n) => print(n * 2));
  ```

  写法简洁，尤其适合集合操作，比如 `map`、`where`、`forEach`。

  箭头函数等价于：

  ```
  (n) {
    return n * 2;
  }
  ```

  ------

  ✅ **小结**

  - 无名函数灵活，可以写多行逻辑，也能捕获外部变量。
  - 箭头函数简洁，适合单表达式，常见于集合操作。
  - 常见误区：
    - 箭头函数里不能写多行语句。
    - 在复杂回调里直接写无名函数，可能导致可读性下降。
