## **第4章 関数とスコープ**

### **4.1 関数の定義と呼び出し**

```
void sayHello(String name) {
  print('こんにちは, $name');
}

void main() {
  sayHello('Anna');
}
```

⚠️ 注意：

- Dart の関数はトップレベルまたはクラス内に定義する。
- 戻り値型は省略可能だが、明示する方が可読性が高い。

------

### **4.2 パラメータの種類（必須・オプション・名前付き・デフォルト値）

#### **必須パラメータ**

```
void greet(String name) {
  print('こんにちは, $name');
}

greet('Anna'); // ✅
```

⚠️ 注意：

- `[]` や `{}` を使わない場合は必須。
- Dart はメソッドオーバーロードをサポートしない。

------

#### **位置オプションパラメータ**

```
void greet(String name, [int? age]) {
  print('Hello $name, age: $age');
}

greet('Anna');    // age=null
greet('Bob', 25); // age=25
```

⚠️ 注意：

- `[]` で囲むとオプションになる。
- `?` を付けると null を許容できる。

------

#### **名前付きパラメータ**

```
void greet({String? name, int? age}) {
  print('Hello $name, age: $age');
}

greet(name: 'Anna', age: 20);
```

⚠️ 注意：

- `{}` で囲むと名前付きパラメータになる。
- 呼び出し時に `name:` を必ず指定。

------

#### **required 修飾子**

```
void greet({required String name, int age = 18}) {
  print('Hello $name, age $age');
}

greet(name: 'Anna'); // ✅
```

⚠️ 注意：

- `required` を付けると必須入力になる。
- Flutter の古いコードでは `@required` が使われていた。

------

#### **デフォルト値**

```
void greet(String name, {int age = 18}) {
  print('Hello $name, age $age');
}
```

⚠️ 注意：

- デフォルト値はコンパイル時定数である必要がある。
- `const` を使えばリストやマップもデフォルトにできる。

------

#### **混合パラメータ**

```
void greet(String title, {required String name, int age = 18}) {
  print('$title $name, age $age');
}
```

⚠️ 注意：

- 順序は「必須 → 位置オプション → 名前付き」。
- 引数が多すぎる場合はデータクラスを検討するとよい。

------

### **4.3 無名関数とアロー関数**

```
var numbers = [1, 2, 3];

numbers.forEach((n) {
  print(n * n);
});

numbers.forEach((n) => print(n * 2));
```

⚠️ 注意：

- アロー関数 `=>` は1つの式しか書けない。
- 無名関数はコールバックに便利。

------

### **4.4 スコープとクロージャ**

```
Function makeCounter() {
  var count = 0;
  return () {
    count++;
    return count;
  };
}

void main() {
  var counter = makeCounter();
  print(counter()); // 1
  print(counter()); // 2
}
```

⚠️ 注意：

- クロージャは外部変数をキャプチャして状態を保持する。
- ループ内でクロージャを作ると、変数の共有に注意が必要。

------

### **4.5 高階関数**

```
int apply(int x, int Function(int) f) {
  return f(x);
}

void main() {
  print(apply(5, (n) => n * 2)); // 10
}
```

⚠️ 注意：

- Dart では関数は「第一級オブジェクト」。引数や戻り値に使える。
- 関数型を明示すると IDE の補完やエラー検出がわかりやすくなる。



### **小结**

- Dart 参数分为 **必选参数、可选位置参数、命名参数** 三类。
- 可以通过 **required** 强制命名参数必须传入。
- **默认值** 只能是编译时常量。
- 推荐：**多参数函数 → 使用命名参数**，提升可读性和可维护性。
- 函数参数过多时，建议改用 **数据类（Data Class）** 或 **配置对象** 传递。
