## **第4章 函数与作用域**

### **4.1 函数的定义与调用**

```
void sayHello(String name) {
  print('你好, $name');
}

void main() {
  sayHello('Anna');
}
```

⚠️ 使用注意点：

- Dart 函数必须写在类或库作用域中，不能嵌套在表达式里。
- 返回值类型可省略，但推荐显式写出，提高可读性。

------



### 4.2 参数形式（必选、可选、命名、默认值）

#### **必选参数（Positional Required）**

```
void greet(String name) {
  print('你好, $name');
}

greet('Anna'); // ✅ 必须传入
// greet();    // ❌ 错误：缺少参数
```

⚠️ 使用注意点：

- 函数定义中不写 `[]` 或 `{}` 的参数就是必选。
- Dart 不支持方法重载，参数数量必须匹配。

------

#### **可选位置参数（Positional Optional）**

```
void greet(String name, [int? age]) {
  print('Hello $name, age: $age');
}

greet('Anna');        // age=null
greet('Bob', 25);     // age=25
```

⚠️ 使用注意点：

- 用 `[]` 包裹，表示可选。
- 可与 `?` 一起使用表示可空。
- 可选参数过多时，不易维护，建议改为命名参数。

------

#### **命名参数（Named Parameters）**

```
void greet({String? name, int? age}) {
  print('Hello $name, age: $age');
}

greet(name: 'Anna', age: 20);
greet(age: 30); // 只传 age
```

⚠️ 使用注意点：

- 用 `{}` 包裹，调用时必须用 `name:` 这种形式指定。
- 命名参数默认是可选的。

------

#### **required 修饰符**

```
void greet({required String name, int age = 18}) {
  print('Hello $name, age $age');
}

greet(name: 'Anna'); // ✅
greet();             // ❌ 缺少必填参数
```

⚠️ 使用注意点：

- `required` 关键字要求调用者必须传参。
- 常和 `@required` 注解（旧版本）对比，但新语法推荐直接用 `required`。

------

#### **默认值（Default Values）**

```
void greet(String name, {int age = 18}) {
  print('Hello $name, age $age');
}

greet('Anna');        // age=18
greet('Bob', age: 25);
```

⚠️ 使用注意点：

- 默认值必须是编译时常量。

- 对象或集合可以用 `const` 初始化：

  ```
  void foo({List<int> nums = const [1, 2]}) {
    print(nums);
  }
  ```

------

#### **混合参数（Mixing Parameters）**

```
void greet(String title, {required String name, int age = 18}) {
  print('$title $name, age $age');
}

greet('Dr.', name: 'Anna'); 
```

⚠️ 使用注意点：

- 顺序：必选参数 → 可选位置参数 → 命名参数。
- 混用时要注意可读性，推荐控制在 3–4 个参数以内。

------

### **4.3 匿名函数与箭头函数**

```
var numbers = [1, 2, 3];

numbers.forEach((n) {
  print(n * n);
});

numbers.forEach((n) => print(n * 2));
```

⚠️ 使用注意点：

- 箭头函数 `=>` 只能写单个表达式。
- 匿名函数常用在回调中，避免定义过多小函数。

------

### **4.4 作用域与闭包**

```
Function makeCounter() {
  var count = 0;
  return () {
    count++;
    return count;
  };
}

void main() {
  var counter = makeCounter();
  print(counter()); // 1
  print(counter()); // 2
}
```

⚠️ 使用注意点：

- 闭包会“捕获”外部变量并保持状态。
- 在循环中创建闭包时要小心，可能导致所有闭包共享同一个变量。

------

### **4.5 高阶函数**

```
int apply(int x, int Function(int) f) {
  return f(x);
}

void main() {
  print(apply(5, (n) => n * 2)); // 10
}
```

⚠️ 使用注意点：

- Dart 把函数当成“一等公民”，能像变量一样传递。
- 建议为参数函数写清晰的类型签名，避免调试困难。



### **まとめ**

- Dart のパラメータは **必須、位置オプション、名前付き** に分類される。
- 名前付きパラメータは `required` を付けることで必須にできる。
- デフォルト値はコンパイル時定数に限定される。
- 引数が多い関数では **名前付きパラメータ** を使うと可読性が向上する。
- さらに複雑な場合は **データクラス** を導入して整理するのが望ましい。
