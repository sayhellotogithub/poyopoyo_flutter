## **4.2 Parameter Types (Required, Optional, Named, Default)**

### Required Parameters

The most common form, must always be provided.

```
void greet(String name) {
  print('Hello, $name');
}

greet('Anna'); // ✅
```

------

### Optional Positional Parameters

Declared in `[]`, can be omitted.

```
void greet(String name, [int? age]) {
  print('Hello $name, age: $age');
}

greet('Anna');    // age=null
greet('Bob', 25); // age=25
```

------

### Named Parameters

Declared in `{}`, called with explicit names.

```
void greet({String? name, int? age}) {
  print('Hello $name, age: $age');
}

greet(name: 'Anna', age: 20);
```

#### required Modifier

Forces named parameters to be mandatory.

```
void greet({required String name, int age = 18}) {
  print('Hello $name, age $age');
}

greet(name: 'Anna'); // ✅
```

### Default Values

Provide default values when arguments are omitted.

```
void greet(String name, {int age = 18}) {
  print('Hello $name, age $age');
}

greet('Anna');        // age=18
greet('Bob', age: 25);
```

------

✅ **Summary**

- Dart parameters come in three forms: **required, optional positional, named**.
- Use `required` to enforce mandatory named parameters.
- Default values must be compile-time constants.
- Common mistakes:
  - Forgetting `required` and missing critical arguments.
  - Using too many optional positionals, reducing readability.
