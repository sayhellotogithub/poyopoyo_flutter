- ## **4.3 Anonymous and Arrow Functions**

  ### Anonymous Functions

  Anonymous functions are functions without a name, often used for callbacks or temporary logic.

  ```
  var list = [1, 2, 3];
  
  list.forEach((int n) {
    print(n * n);
  });
  ```

  They can take parameters, return values, and capture external variables, forming closures.

  ------

  ### Arrow Functions

  Arrow functions are a shorthand for anonymous functions, using `=>` for single expressions.

  ```
  var list = [1, 2, 3];
  
  list.forEach((n) => print(n * 2));
  ```

  This is equivalent to:

  ```
  (n) {
    return n * 2;
  }
  ```

  ------

  ✅ **Summary**

  - Anonymous functions are flexible and can hold multiple statements.
  - Arrow functions are concise, ideal for single expressions, and common in collection methods.
  - Common mistakes:
    - Trying to write multiple statements in an arrow function.
    - Putting too much complex logic inside anonymous functions, reducing readability.
