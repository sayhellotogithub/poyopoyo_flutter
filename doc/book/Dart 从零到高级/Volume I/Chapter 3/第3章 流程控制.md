## **第3章 流程控制**

------

### **3.1 if / else 分支**

用于根据条件执行不同逻辑：

```
var age = 20;
if (age >= 18) {
  print('成年人');
} else {
  print('未成年人');
}
```

⚠️ **使用注意点**：

- 条件必须返回布尔值 (`true` 或 `false`)，不能像某些语言那样用 `0`/`1` 代替。
- 推荐使用花括号 `{}` 包裹代码块，哪怕只有一行，避免维护时引入错误。

------

### **3.2 switch / case 多分支**

适合多条件分支：

```
var grade = 'B';
switch (grade) {
  case 'A':
    print('优秀');
    break;
  case 'B':
    print('良好');
    break;
  default:
    print('未知等级');
}
```

⚠️ **使用注意点**：

- 每个 `case` 必须使用 `break`（或 `return`/`throw` 等）显式结束，否则会继续执行下一个分支。
- `switch` 支持 `String`、`int`、`enum`，但不支持复杂表达式。

------

### **3.3 循环结构**

- **for 循环**：

  ```
  for (var i = 0; i < 3; i++) {
    print('循环 $i');
  }
  ```

- **while 循环**：

  ```
  var count = 0;
  while (count < 3) {
    print(count);
    count++;
  }
  ```

- **do-while 循环**：

  ```
  var x = 0;
  do {
    print(x);
    x++;
  } while (x < 3);
  
  ```

*  **forEach 方法**

```
var numbers = [1, 2, 3];
numbers.forEach((n) => print(n));
```

*  **带标签的循环（labeled loops）**

```
outerLoop:
for (var i = 0; i < 3; i++) {
  for (var j = 0; j < 3; j++) {
    if (j == 1) continue outerLoop; // 跳过外层循环
    print('i=$i, j=$j');
  }
}
```

⚠️ 使用注意点：

for 更适合已知次数的循环，while 更适合未知次数的循环。

避免死循环 (while(true))，需要加退出条件。

`forEach` 更适合简洁写法，但无法使用 `break` 或 `continue` 控制循环。

标签循环常用于多层嵌套时控制外层循环，使用时要小心，避免代码难以理解。

------

### **3.4 break 与 continue**

```
for (var i = 0; i < 5; i++) {
  if (i == 2) continue; // 跳过本次
  if (i == 4) break;    // 提前结束
  print(i);
}
```

⚠️ **使用注意点**：

- `continue` 会跳过当前循环，但不会终止整个循环。
- `break` 只会跳出当前循环，不会影响外层循环。

------

### **3.5 异常处理**

```
try {
  var result = 10 ~/ 0; // 整数除零
} catch (e) {
  print('发生异常: $e');
} finally {
  print('执行完成');
}
```

⚠️ **使用注意点**：

- `~/` 是整除运算符，除以零会抛出异常。
- `finally` 中的代码总会执行，即使 `try` 或 `catch` 里有 `return`。
- 不要滥用 `catch (e)`，实际开发中应区分异常类型。
