## **第3章 制御構文**

------

### **3.1 if / else 文**

条件に応じて処理を分岐します：

```
var age = 20;
if (age >= 18) {
  print('大人');
} else {
  print('未成年');
}
```

⚠️ **注意**：

- 条件式は必ず `bool` を返す必要があります。他言語のように `0/1` を使うことはできません。
- 一行であっても `{}` を付けることを推奨します。

------

### **3.2 switch / case 文**

複数条件の分岐に便利です：

```
var grade = 'B';
switch (grade) {
  case 'A':
    print('優秀');
    break;
  case 'B':
    print('良好');
    break;
  default:
    print('不明な評価');
}
```

⚠️ **注意**：

- 各 `case` の末尾に `break` が必要です。
- `switch` は `int`、`String`、`enum` に使えますが、複雑な式は利用できません。

------

### **3.3 ループ構造**

#### **標準 for ループ**

```
for (var i = 0; i < 3; i++) {
  print('ループ $i');
}
```

⚠️ 注意：回数が決まっている場合に便利。条件設定を誤ると無限ループになる。

------

#### **while ループ**

```
var count = 0;
while (count < 3) {
  print(count);
  count++;
}
```

⚠️ 注意：条件が満たされなくなることを保証しないと無限ループになる。

------

#### **do-while ループ**

```
var x = 0;
do {
  print(x);
  x++;
} while (x < 3);
```

⚠️ 注意：条件が偽でも必ず1回は実行される。

------

#### **for-in ループ（コレクションの走査）**

```
var list = ['A', 'B', 'C'];
for (var item in list) {
  print(item);
}
```

⚠️ 注意：Iterable を対象とする。走査中にコレクションを変更しないこと。

------

#### **forEach メソッド**

```
var numbers = [1, 2, 3];
numbers.forEach((n) => print(n));
```

⚠️ 注意：`break` や `continue` は使えない。制御が必要な場合は `for-in` を使う。

------

#### **ラベル付きループ**

```
outerLoop:
for (var i = 0; i < 3; i++) {
  for (var j = 0; j < 3; j++) {
    if (j == 1) continue outerLoop;
    print('i=$i, j=$j');
  }
}
```

⚠️ 注意：多重ループで外側の制御が必要なときに使える。ただし読みづらくなるので乱用は避ける。

------

### **3.4 break と continue**

```
for (var i = 0; i < 5; i++) {
  if (i == 2) continue; // スキップ
  if (i == 4) break;    // 途中終了
  print(i);
}
```

⚠️ **注意**：

- `continue` は現在の反復だけをスキップします。
- `break` は内側のループのみを終了します。

------

### **3.5 例外処理**

```
try {
  var result = 10 ~/ 0; // 整数のゼロ除算
} catch (e) {
  print('例外発生: $e');
} finally {
  print('処理完了');
}
```

⚠️ **注意**：

- `~/` は整数除算演算子です。ゼロ除算は例外になります。
- `finally` は必ず実行されます。
- 実際の開発では例外の種類を分けて処理することが推奨されます。
