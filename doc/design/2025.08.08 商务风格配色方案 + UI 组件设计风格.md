商务风格配色方案 + UI 组件设计风格

「**商务风格配色方案 + UI 组件设计风格**」，适用于企业后台、SaaS平台、B2B产品、数据仪表盘等场景。

## 1. 商务风格推荐配色方案

### ✅ A. 通用商务蓝灰风格（默认推荐）

| 用途        | 色值      | 示例                     |
| ----------- | --------- | ------------------------ |
| 主要颜色    | `#2F80ED` | 蓝色（按钮、主题色）     |
| 次要颜色    | `#56CCF2` | 浅蓝（Hover 或次要按钮） |
| 背景色      | `#F8F9FA` | 主背景（页面背景）       |
| 卡片背景    | `#FFFFFF` | 卡片、组件背景           |
| 边框/分隔线 | `#E0E0E0` | 表单、卡片边框           |
| 字体主色    | `#212121` | 主要文字（黑灰）         |
| 字体副色    | `#757575` | 辅助说明文字             |
| 错误色      | `#EB5757` | 表单错误、警告等         |
| 成功色      | `#27AE60` | 成功提示、状态标识       |



👉 适合打造稳重、现代、清爽的企业应用视觉体验。

### B. 深色商务风格（用于可选暗黑模式）

| 用途     | 色值      |
| -------- | --------- |
| 主背景   | `#1F1F1F` |
| 卡片背景 | `#2C2C2C` |
| 文字主色 | `#E0E0E0` |
| 主按钮色 | `#2F80ED` |
| 分隔线   | `#3D3D3D` |

建议支持 `light/dark` 模式切换，可用 Riverpod 管理主题模式。

## 2. UI组件设计风格建议

### ✅ 表单与按钮组件（统一风格）

- **按钮**：

  - 主按钮：`ElevatedButton` + 主要颜色 `#2F80ED`
  - 次按钮：`OutlinedButton` + hover 色 `#56CCF2`
  - 禁用状态：低饱和灰色 `#BDBDBD`

- **表单组件统一样式**：

  ```
  dart
  
  
  复制编辑
  InputDecorationTheme(
    border: OutlineInputBorder(),
    focusedBorder: OutlineInputBorder(
      borderSide: BorderSide(color: Color(0xFF2F80ED)),
    ),
    labelStyle: TextStyle(color: Color(0xFF212121)),
    hintStyle: TextStyle(color: Color(0xFF757575)),
  )
  ```

### 卡片、表格、导航栏

- **卡片风格**：

  ```
  dart
  
  
  复制编辑
  Card(
    elevation: 2,
    shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
    child: Padding(...),
  )
  ```

- **数据表格**：
   使用 `PaginatedDataTable` 或自定义 `Table`，统一使用中性边框色 `#E0E0E0`，表头加粗。

- **侧边栏 / 顶部导航栏**：

  - 背景色：`#2F80ED` or `#1A237E`
  - 图标 + 字体使用白色 `#FFFFFF`
  - 激活菜单项带蓝色下划线或背景高亮

## 3. 字体与布局建议

| 元素   | 样式建议                                               |
| ------ | ------------------------------------------------------ |
| 标题   | `TextStyle(fontSize: 20, fontWeight: FontWeight.bold)` |
| 正文   | `TextStyle(fontSize: 14, color: Color(0xFF212121))`    |
| 辅助   | `TextStyle(fontSize: 12, color: Color(0xFF757575))`    |
| 字体族 | 默认 `Roboto` 或引入 `Noto Sans`（多语言友好）         |



- 页面左右内边距建议：`padding: EdgeInsets.symmetric(horizontal: 24)`
- 页面宽度限制：`maxWidth: 1200`，居中显示

## 4. Flutter 主题定义建议（ThemeData）

在 `core/theme/app_theme.dart` 中管理：

```dart
final lightTheme = ThemeData(
  brightness: Brightness.light,
  primaryColor: Color(0xFF2F80ED),
  scaffoldBackgroundColor: Color(0xFFF8F9FA),
  textTheme: TextTheme(
    titleLarge: TextStyle(fontSize: 20, fontWeight: FontWeight.bold),
    bodyMedium: TextStyle(fontSize: 14, color: Color(0xFF212121)),
  ),
  inputDecorationTheme: ...,
  appBarTheme: AppBarTheme(
    backgroundColor: Colors.white,
    foregroundColor: Color(0xFF212121),
    elevation: 1,
  ),
);
```
